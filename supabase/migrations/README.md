# Canonical Atlas migration root

This directory is generated by
`npm run db:reconstruct-baseline`; do not edit generated migrations by hand.

The 49 filenames preserve Atlas production's exact migration-ledger
version/name order. The first existing production version contains a transparent
current production-derived schema squash. The remaining 48 files are immutable
no-op ledger receipts: they preserve historical identity without pretending the
incomplete production overlay was founding DDL.

`../migration-manifest.json` records the chain as `candidate` until a fresh
PostgreSQL 17/Supabase replay, dirty no-op replay, second clean replay, hosted
preview parity check, pgTAP, lint, and advisor review all pass. Production is
read-only throughout this process.

The source catalog, hashes, exclusions, hardening decisions, and generated-file
hashes are recorded in
`../evidence/current-production-catalog/reconstruction-manifest.json`.
