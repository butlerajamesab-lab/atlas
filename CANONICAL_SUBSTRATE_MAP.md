# SEMANTIC DOCTRINE

## Core Separation Rules

events ≠ domains ≠ Civic signals

These layers must never be collapsed together.

| Concept | Meaning |
|---|---|
| events | Operational telemetry and ingestion evidence |
| domains | Semantic ontology overlays |
| workflows | Procedural topology structures |
| Civic signals | Governance fractures, contradictions, anomalies |
| prime patterns | Persistent emergent systemic structures |

## Rules

- Domains annotate events.
- Events do not become signals.
- Signals emerge from convergence, contradiction, overlap, drift, escalation, and topology analysis.
- Prime patterns emerge from persistent signal convergence.
- Bridges preserve ontology; they do not reinterpret it.

---

# PROHIBITED OPERATIONS

The following are prohibited without explicit reconciliation review:

- duplicate jurisdiction systems
- shadow registries
- alternate signal stores
- parallel workflow authorities
- bridge-layer ontology reinterpretation
- assistant-created substrate duplication
- runtime-specific ontology forks
- silent schema replacement

All new systems must attach to canonical substrate authorities.

# GOVERNANCE SIGNAL DOCTRINE

Governance signals are structural anomalies.

Signals are NOT:
- events
- alerts
- dashboards
- domains

Signals ARE:
- contradictions
- overlaps
- escalation loops
- weak joints
- orphaned pathways
- burden shifts
- unresolved inheritance
- precursor suppression
- systemic instability

## Canonical Governance Signals

| Signal | Meaning |
|---|---|
| contradiction_detected | Structural mismatch |
| overlap_detected | Duplicate authority or pathway |
| escalation_loop_detected | Recursive procedural failure |
| weak_joint_detected | Structural instability zone |
| precursor_ignored | Suppressed warning signal |
| orphaned_pathway | Broken resolution chain |
| burden_shift_detected | Systemic displacement of responsibility |
| inheritance_conflict | Governance composition failure |
| unresolved_reconciliation | Canonical resolution failure |
